# 批量删除新浪微博，自动化工具，告别微博黑历史

## 前言

前阵子整理旧账号，翻到自己 10 年前的微博。

十年老帐号了，注销又没必要，清空以前发的微博就可以了。

那会儿，一天能发七八条，什么“今天天气真好”、转发的段子、跟人吵架的记录，全在那儿躺着。十几年攒下来小一万条。

我一开始是手动删的。点开一条，找“更多”，点“删除”，弹窗点“确定”。四条操作删一条，删了二十分钟手就酸了，一看进度——才删掉三十条。

按这个速度，删完得连着点三天。

更气的是，微博网页版压根没给批量删除的功能。官方帮助里写得明明白白：只能一条条删。第三方工具倒是有，但要么收费，要么要你把账号密码交出去，要么装一堆流氓软件。

所以写了一个微博内容批量删除工具。

## 它干什么

一句话：**登录一次，剩下它自己删。**

双击运行，弹出一个浏览器窗口让你扫码登录微博。登完之后你就不用管了，它自己一页一页翻你的微博，一条一条删。

屏幕上的黑窗口会实时打印进度：

```
[1] 删了 4251884284009913  有几种人我真的佩服得不要不要的...
[2] 删了 4251808761221441  忙是治疗一切神经病的良药...
[3] 删了 4251733171622514  人都是被自己打败的...
```

平均两三秒一条。

一万条微博，大概六个小时。挂那儿跑一晚上，第二天早上就干净了。

## 几个我觉得挺实用的点

**可以按日期删。**

全删有点舍不得，毕竟有些年头的记录还留着当个念想。但 2013 到 2016 那几年确实没眼看，可以只删这段：

```bash
python weibo_delete.py --start 2013-01-01 --end 2016-12-31
```

首尾两天都包含在内。只填开始日期就是“从这天之后全删”，只填结束日期就是“这天之前全删”。

**能断点续删。**

一万条删到一半，电脑死机了、网断了、你按了 Ctrl+C——都没关系。它会记住已经删掉哪些，下次跑自动跳过，从断的地方接着来。

数据是每删一条就立刻写进硬盘的，哪怕进程被强杀也丢不了。

**被限速会自己歇着。**

微博对批量操作有限制，删太快会返回“操作频繁”。工具遇到这种情况会退避重试——先歇 30 秒，还不行就歇 60 秒，再不行 120 秒，最多歇 15 分钟。

另外它本身就带限速，默认每条之间等 2 秒再加一点随机浮动。不追求快，追求跑得完。

**网络抖动不会导致漏删。**

这点我特意加固过。网络不好、服务端临时抽风时，删除会失败，但这类临时错误工具会重试 5 次；5 次都失败也不写进跳过记录，下次运行会重新尝试。只有真正删不掉的（原作者设了权限、微博已不存在）才会被永久跳过。

被跳过的记录可以在菜单里选 [8] 清空，让它们重新试一次。

**快转也能删。**

早年转发的段子、视频，微博改版后叫“快转”。这类和普通微博的删除方式不同，得用原微博的 id 去取消快转。工具会自动识别，失败了还会换一条路重试。

**不用交账号密码。**

这是我最在意的一点。它用的是 Playwright——你可以理解成它开了个真的 Chrome 浏览器，你在这个浏览器里正常扫码登录，登录状态存在本地。之后所有的操作都是在这个浏览器里发出的，用你自己的 cookie。

账号密码自始至终没离开过你的电脑。第三方服务器什么的，不存在的。

## 怎么用

三步。

**第一步，下载。**

打开 https://github.com/yezijinn/weibo-delete

点绿色的 Code 按钮，选 Download ZIP。下载完解压。

**第二步，装环境。**

电脑上得有 Python。没有的话去 python.org 下一个，安装的时候记得勾上 “Add Python to PATH”——这步漏了后面会报错，很多人栽在这儿。

然后双击解压出来的 `install.bat`。黑窗口会自己装东西，大概一两分钟，要下载 150MB 左右。中途别关窗口。

**第三步，开删。**

双击 `run.bat`，出来一个菜单：

```
==============================================
           微博批量删除工具
==============================================

   [1] 先看看有多少条（不删，推荐先跑这个）
   [2] 全部删除
   [3] 按日期删除
   [4] 先删 3 条试试（验证能不能用）
   [5] 手动输入命令
   [6] 退出登录（换一个账号用）
   [7] 设置删除间隔（当前每条 2.0 秒）
   [8] 重试之前跳过的微博
   [0] 退出
```

输数字回车就行。

第一次运行会弹出微博登录页，手机扫码。之后就不用再登了。

**强烈建议先选 [1] 看看有多少条，再选 [4] 试删三条。**

确认能正常删，再动真格的。

## 有几件事得说清楚

**删了就是删了，找不回来。**

微博没有回收站。这是我把这个工具做出来之前纠结最久的一点，所以也把它放在 README 第一行：先用 [1] 数数，再用 [4] 试三条，最后才全删。

**评论、点赞、关注删不了。**

微博、快转都能删。但评论、点赞、关注这些不行——不是工具不行，是微博网页版根本没提供批量清理入口。真要清理得走另一套方案（比如手机端自动化），那是另一个工程量级的事。

**不是 100% 稳。**

它调用的是微博网页版的内部接口，这些接口哪天改了，工具就失效了。我尽量把报错信息打清楚，出问题看 `data/run.log` 能定位原因。

另外微博的风控策略也会变，可能某天你会发现删得比平时慢，或者频繁被限速——那就停几个小时再跑。

**Windows 专用。**

我是 Windows 用户，脚本里的安装包和启动器都是 .bat。代码本身是 Python，理论上 Mac 和 Linux 也能跑（把 .bat 换成 shell 脚本），但我没测过。
